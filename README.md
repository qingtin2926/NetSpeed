# NetSpeed Monitor 🚀 (极简 macOS 状态栏实时网速)

专为 **Apple Silicon (M4 MacBook Air)** 与 macOS 打造的原生超轻量状态栏实时网速监视软件。

---

## 🌟 核心特性

- ⚡ **极致低资源消耗**：
  - 纯原生 Cocoa (AppKit) + Objective-C 编写，**0 第三方重型依赖**（非 Electron/Webview，无庞大运行时）。
  - 原生 Apple Silicon (arm64) 编译并开启 `-O3` 深度性能优化。
  - **常驻内存仅约 6~8 MB**，**CPU 占用低于 0.02%**，对 M4 MacBook Air 的电池续航与发热零负担。
- 🙈 **右下角 / 程序坞 (Dock) 零占位**：
  - 配置系统级 `LSUIElement = true`，作为纯后台 Agent（Accessory）运行。
  - **Dock 栏完全不出现图标**，不占用右下角/底栏位置，也不干扰 Command + Tab 应用切换。
- 📊 **状态栏精致排版与绝对零位移（Zero-Jitter）**：
  - **始终保留一位小数 + 严格等宽占位 + 自动进位**：
    - 0 ~ 999.9 KB/s：严格保留一位小数（如 `  0.0 KB/s`, `  8.2 KB/s`, ` 13.5 KB/s`, `120.5 KB/s`）
    - 超过 999.9 KB/s：自动进位为 MB/s（如 `  1.0 MB/s`, ` 15.8 MB/s`, `120.0 MB/s`）
    - 超过 999.9 MB/s：自动进位为 GB/s（如 `  1.5 GB/s`）
  - **全等宽系统字体 (SF Mono) + 固定 Item Length**：
    - 字符数恒定为 12 字符，渲染宽度精确恒等于 66.762 pt。
    - `NSStatusItem.length` 锁死固定宽度，**从根本上彻底杜绝数字变动推挤菜单栏左右晃动的问题**！
  - **垂直紧凑双行模式（默认）**：
    ```text
    ▲  13.5 KB/s
    ▼   1.2 MB/s
    ```
    精巧居中贴合 macOS 22~24pt 菜单栏高度，大幅节省菜单栏横向空间。
  - **水平单行模式**：`▲  13.5 KB/s  ▼  1.2 MB/s`，同样保持严格固定宽度。
- 🛡️ **精准流量计算（防代理/VPN 翻倍）**：
  - 底层基于 BSD `getifaddrs` 系统调用。
  - 智能统计物理网络接口（`en0` 等），在使用 Clash / Surge / WireGuard 等虚拟网卡（`utun`）时，不会发生外网流量翻倍统计的假数据问题。
  - 内置 32 位溢出回绕（Wrap-around）平滑处理算法，传输上百 GB 数据也能精准计数。
- 🖱️ **便捷交互与功能菜单**：
  - 点击状态栏网速文字即可唤出精美菜单：
    - 查看实时上传/下载精准速率
    - 查看本次开机/启动以来的累计上传/下载总流量
    - 查看当前活跃的主网卡名称（如 `en0` Wi-Fi）
    - 快速切换显示模式（垂直双行 / 水平单行）
    - 快速切换箭头样式（三角箭头 `▲▼` / 线性箭头 `↑↓`）
    - 快速切换刷新频率（0.5s / 1.0s / 2.0s）
    - 一键切换【开机自动启动】
    - 重置本次统计 / 退出应用

## 🛠️ 一键安装与运行

在终端中进入当前目录，直接执行一键脚本即可完成编译、打包并安装到 `/Applications`：

```bash
./build_and_install.sh
```

或者使用 `make` 命令逐步操作：

```bash
# 1. 编译并打包应用
make all

# 2. 安装到系统的 /Applications/NetSpeed.app
make install

# 3. 启动应用
make run
```

启动后，您将在 Mac 屏幕顶部的状态栏（右上角）看到实时的网速数据！同时右下角（Dock 栏）没有任何图标占用。

---

## ⚙️ 快捷控制指令

| 命令 | 说明 |
| :--- | :--- |
| `make run` | 启动 NetSpeed |
| `make stop` | 退出 NetSpeed |
| `make status` | 查看运行进程及 CPU/内存状态 |
| `make clean` | 清除编译产物 |

---

## 🖥️ 偏好设置与持久化

- 应用的显示模式、箭头风格、刷新间隔等设置会自动通过 `NSUserDefaults` 保存在本地，下次启动或重启电脑后自动保留您的偏好。
- 在下拉菜单中点击 **“开机自动启动”** 即可一键设置开机自启（在现代 macOS 系统中采用官方 `SMAppService` / `LaunchAgents` 规范）。
